# Project Overview

## Project Name
Knowledge App

## Project Type
Personal Knowledge Management System (PKM)

## Purpose
Knowledge App enables users to capture, organize, connect, and explore personal knowledge through two complementary mental models:

1. **Hierarchical Tree Structure** — Notes organized in parent-child trees with unlimited depth
2. **Knowledge Graph Structure** — Independent, typed relationships between any notes

## Core Principle
> **Notes are the center of the entire application.**

Every feature exists to serve the note — creation, organization, connection, search, and visualization.

## Problem Statement
Knowledge workers accumulate large amounts of information across different tools. The challenge is not storing information but *connecting* it — understanding how concepts relate, depend on, and extend each other.

Knowledge App solves this by combining:
- Familiar hierarchical organization (like a folder tree)
- Powerful relationship mapping (like a knowledge graph)
- Rich text content editing (like a document editor)

## Target User
An individual knowledge worker who wants to:
- Take rich, structured notes
- Organize notes into logical hierarchies
- Connect related concepts across different topics
- Discover knowledge through graph exploration
- Search and filter their knowledge base efficiently

## Key Differentiators
| Feature | Description |
|---------|-------------|
| Dual Organization | Both tree hierarchy AND independent graph relationships |
| Relationship Types | Typed connections: related, depends, references, extends, contradicts |
| Backlinks | See what other notes reference the current note |
| Knowledge Graph | Visual graph exploration with React Flow |
| Rich Text | Full-featured editing via TipTap |
